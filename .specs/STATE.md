| AD-030 | The mouse drives the same gesture machine as a finger, and `TouchSimulation` is gone. `InputRouter` picks the mouse up only when no touch is on screen, applies the same tap-versus-drag rules to it, and asks the EDGE-02 gate with uGUI's left-button pointer id | active | 2026-08-18 | Selection worked in the Device Simulator and nowhere else: the room reads EnhancedTouch, and outside the simulator the only bridge was `TouchSimulation`, which is an editor-only global singleton.
